# Инструмент визуализации графа зависимостей для менеджера пакетов

Инструмент визуализации графа зависимостей для менеджера пакетов. Формат пакетов Python (pip). Текстовое представление графа генерируется на языке Mermaid. Получение данных о пакетах в формате JSON осуществяляется через PyPI API 

## Функционал

Источником настраиваемых пользователем параметров являются опции командной строки.

К настраиваемым параметрам относятся:
* Имя анализируемого пакета
* URL-адрес репозитория или путь к файлу тестового репозитория
* Режим работы с тестовым репозиторием
* Имя сгенерированного файла с изображением графа
* Режим вывода зависимостей в формате ASCII-дерева

Пример ввода
```bash
python dependency_visualizer.py --package "A" --source "test_repo_cycle.txt" --test-mode --ascii-tree
```
## Сборка проекта

Для визуализации графа с использованием языка Mermaid необходимо скачать на свое устройство Node.js с сайта [nodejs.org](https://nodejs.org/en) и запустить следующие комманды.

```bash
npm install -g @mermaid-js/mermaid-cli
git clone git@github.com:thaperfectcell/conf_upr_dependencies_visualizer.git
python dependency_visualizer.py --package "A" --source "test_repo_simple.txt" --test-mode --ascii-tree
```
Для работы с реальными пакетами необходимо убрать флаг ```--test-mode``` и в параметре ```--source``` указать ```https://pypi.org```
